# 重生长雍帝王赋

清宫重生题材的文字经营叙事游戏。玩家是重生回到雍正元年的雍正，在三十年里处理朝政，也重新面对七段旧日关系：苏培盛、年羹尧、温实初、允礼、宜修、年世兰、安陵容，另有甄嬛、沈眉庄两条扩展线。

当前版本 **0.26.0**。本地运行，未发布。

## 运行

需要 Node.js 22.9 或以上，无需安装依赖。

```bash
npm start
```

浏览器打开 http://127.0.0.1:5173/?world=weekly 。端口被占用时用 `PORT=5315 npm start`。

## AI 对白

默认可以不联网，全程使用固定文本。若在 `.env` 或 `123.env` 里填好密钥（默认 DeepSeek Flash，见 `.env.example`），游戏启动后会自动开启 AI 对白；在“更多—设置”里改回固定文本后，会记住这个选择。

## 目录

| 路径 | 内容 |
| --- | --- |
| `src/` | 游戏代码。规则引擎 `engine.js`、`week.js`；各卷内容 `volume*-content.js`；阅读修订稿 `narrative-copy.js` |
| `assets/` | 立绘、背景、封面及导出尺寸 |
| `tests/` | 自动测试，`npm test` |
| `scripts/` | 测试用的剧情场景生成器 |
| `design/` | 设计规范 V1.2、周活动方案与各阶段设计表 |
| `docs/施工/` | 历次施工与验收记录（`施工进度.md` 为完整流水） |
| `output/imagegen/` | 美术原稿 |

## 文字修订机制

原稿正文写在各卷内容文件里，并且保持不动，旧存档里的原话才能对得上。玩家看到的是 `src/narrative-copy.js` 里的阅读修订稿：按场景编号替换正文和回应。要改某一幕的文字，在这个文件里改，不要改原稿。

## 0.26.0 改动（2026年10月29日）：两难

关系选项原本总有一个“正确答案”：亲近的那一项只加信任、没有代价。这一版在前两年加入四个两难场景，成全一人，便会辜负另一人；想两头都顾，就要付出自己的代价。

| 场景 | 时间 | 两难 |
| --- | --- | --- |
| 七夕两宫 | 元年七月 | 宜修依礼拜月，年世兰扎好了鹊桥灯 |
| 再唱一回 | 二年正月 | 安陵容想当众唱完那支曲，年世兰视为当众打脸 |
| 庆功与笛约 | 二年四月 | 年羹尧的庆功宴与允礼的笛约在同一夜 |
| 城南的疫 | 二年七月 | 温实初想去城南救疫，宫里的调养离不开他 |

- 场景在主线之后出现在御案上，占一格时间，可以不打开，错过即不再出现。
- 成全的一方信任上升；被辜负的一方留下一个“心结”，在补谈之前不能再往亲近处走（合作照常）。补谈占一格，每人有专门的补谈对白。
- 两头兼顾的选项不留心结，但会扣圣躬、国库或心绪。
- 之后与当事人相见时，开场会提起这件事；心结未解，就一直提起。
- 内容在 `src/dilemma-content.js`。原有 181 个场景的正文与效果不变，旧存档照常读取；伪造的心结记录会被存档校验拒绝。

另修正：对女性角色的自由对话框显示“亲口对她说”。

## 0.25.0 改动（2026年10月29日）

依据制作人评审意见调整：

- **少打断**：剧情选项不再弹“就这样回答？”确认框；不花钱的“等到下一件要紧事”直接推进。花国库、揭示重生等不可撤回的决定仍会确认。
- **界面去掉内部用语**：御案首页的月账说明、“预占／核销”、旧事簿里的事件编号、人物卡上的“档案肖像 · 所绘年龄”、知情范围清单等都已移除或改成白话。
- **标题页**：开局先显示封面与“开卷／继续”。
- **立绘放大**：场景横幅里的人物立绘约放大 1.5 倍。
- **AI 自动启用**：本机已配置密钥时自动开启 AI 对白。
- **重写结局与中段**（阅读版第 23 版，共 52 处）：
  - 七条核心线的第六节点和七篇暮年番外，以及甄嬛、沈眉庄的结局，从每篇约 70 字扩写成完整场景，每人保留各自的说话方式和信物线索（手炉、舆图、老槐树、半拍、梅林、花册、新曲、梨花、鸟窝）。
  - 三十年终章“三十年灯下”。
  - 中段 11 个关系节点（第三、四节点）、后期 17 个政务场景、15 个日常场景、7 个群像支线，去掉了“不补造”“原件另记”一类的规则说明。
  - 最终史册里每个人的结语与新番外呼应。
  - 未达成相守时的“探望”页、年世兰番外的子女说明，改为自然叙述。
- **清理**：删除阶段保护包、旧截图、旧版规范和一次性验收脚本，项目从 7.5G 降到约 3G。项目已纳入 git，所有改动可回退。
