- 苏培盛、年羹尧、温实初、**果郡王允礼**、宜修、年世兰、安陵容七线各前两个节点，共 14 个。可相知，也可保留合作，拒绝不扣无关职业能力。
- 财政清理、西北军饷两条完整政务链，共 6 个节点；4 个群像支线、8 个可选日常模板。
- 旧季度档推荐路径占13次安排，余3次，卷末最多3次补叙；新周档用六格周计划，按实际工期回访，沿用原文并重新排时，不使用旧补叙额度。

- 饮茶偏好按知情人物分别保存与更正；明确拒绝形成持续边界；重生披露须确认听者与范围。
- 约见、书信和轮值休假有实际日期与容量预约，赴约不再扣第二次。

### 全部档案的恢复方式

“导出当前存档”生成可直接导入的单个进度；“导出全部档案”生成原始档案集合。季度集合可在“旧档接续”内选择一份记录复制迁移；集合不会一次覆盖本机八槽。普通周档集合仍按单档恢复。需要恢复其中一档时，将集合中对应`records`项的`raw`原字串另存为UTF-8 JSON文件，再用“选择存档导入”校验并恢复。`raw`为`null`表示空槽；损坏的原字串也会保留，不能保证通过校验。导入前先导出当前进度，系统亦会保留恢复前自动档。存档按协议、主机和端口分别隔离。

这是首版原型，不代表 V1.2 全部制作目标交付：三年至三十年、各线后四节点、暮年番外、生育及成人婚姻的实际剧情尚未开放；后续仍需扩写、平衡与人工审阅。未制作的内容没有作为可玩按钮开放。

## AI 接入

默认使用固定文本与明确标注的规则输入，无密钥也可完成周制三十年长卷。规则输入不是通用离线语言模型。在 G04 军饷场景可输入：

> 先拨一半，派张廷玉核账，暂不公开怀疑，并加押运

规则会拟成 6 点补给加 2 点押运的方案。取消预览不执行命令；假设咨询不提交；无效附加命令不会被静默舍弃。

### 本地代理

默认联网预设为 DeepSeek Flash（`deepseek-flash`、`https://api.deepseek.com`、Chat Completions）。复制 `.env.example` 为 `.env`，仅在本机填写密钥，再启动：

```sh
npm start
```

在设置中选择“本地服务端代理”。支持 Responses API 及兼容 Chat Completions。DeepSeek按官方JSON对象模式适配并附结构提示，其他服务商沿用严格JSON Schema。程序继续校验事实、命令候选和当前边界。默认模式仍为固定文本，联网需在设置中明确启用；当前无真实密钥，远端验收待完成。

密钥只在服务端环境使用，不会进入游戏存档或页面源码。此代理有本机 Host、Origin、并发与每日调用限制；对公网部署仍需真实鉴权、按用户额度和运营安全配置。

### 自带密钥

设置中显式选择“自带密钥”，填写地址、协议、模型与密钥。只保留在当前页面内存，刷新后清除；上下文发送至指定服务商。浏览器跨域限制可能使直连失败，此时改用本地代理。

AI 可以解析候选命令与组织人物问答，不能修改游戏状态。人物上下文先按可见性筛选，不传递玩家独有的主线内心独白。程序校验结构、事实引用、已知秘密与关系边界；失败回退固定文本。语义检查不是绝对事实保证，仍需使用实际模型做七人人格与长对话评测。

已连接AI时，主线及七线的既定选择完成后，可自动发起一次角色接话请求。手写回应立即可读；AI只补充对白，不修改数值、既定事件或关系阶段。接话在14秒客户端时限内回退，失败不循环调用，重读不再次生成；成功文本随旧事原文保存。跨进度或离开场景的旧回复不写入新场景。

混合句逐项处理；提问子句不生成命令，另一条明确行动仍可形成候选。整句假设不执行。普通咨询直接进入问答，不再先调用一次动作解析。解析接口按本次原子句重建actionCatalog，模型仅返回candidateId与sourceText，旧raw event/promise回包不再接受；本地确定参数不交给模型修改，所有候选仍需当前规则预览。任免、孩子、婚约、关系经历及完成政绩等高影响叙述检出后须有对应世界来源，不能用无关引用作凭据。

目前验证了协议适配器的模拟响应、错误结构、限额和回退，**尚未进行真实服务商端到端调用**。

接口实现参考：[OpenAI 官方 Structured Outputs 文档](https://developers.openai.com/api/docs/guides/structured-outputs)。
