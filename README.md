# 重生长雍帝王赋

清宫重生题材的文字经营叙事游戏。玩家重回雍正元年，在三十年主线中处理朝政，也重新面对苏培盛、年羹尧、温实初、允礼、宜修、年世兰、安陵容七段旧日关系，以及甄嬛、沈眉庄两条扩展线。三十年后可无限续玩。

当前版本 **0.46.0**。旧存档可以继续游玩，无须重开。

## 本版改动

本版新增：一档「言出法随」改为直接改写。首页可随时输入指令，不占时辰；下旨、召见、休养和夜间自拟安排共用改写通道。
资源和人物数值直接入档，任命可突破身份资格与职位定员，也可设自定头衔。新制度、科技等没有专用面板的内容保存为世界事实，供后续 AI 剧情沿用。
明确的资源数值指令可离线执行，例如「国库增加一亿两，圣躬永久设为100」；复杂安排需连接 AI。永久设定可用后续指令修改或解除，二、三档沿用原规则，旧存档无须重开。
审计、缓存与美术验收见 [0.46 发布验收](docs/施工/0.46-审计缓存美术验收.md)。

- 正月只需完成「养心惊梦」即可自由行动，茶叙合并后移至二月；另有一件免费、当月可办的朝政小事。
- 只有「除夕守岁」和中秋必须处理；其余节庆在首页自由选择，不花时辰，错过后不扣分、不顺延。旧档尚未过的节庆会移到相应卡片。
- 首页先列要事和行动，朝局详情可展开；情分注明本月变化，入夜和重开都有页面内确认。
- 折匣浏览免费，第一次落笔才扣时辰，一次可批6道，设值房后10道；奏折更简短，边务由边省上奏。
- 月报涨跌标签更清楚，零值或未开启的入账项隐藏，国库支出列出去向。
- 调整军政用度和内帑花费；连续三个月未联络才略降情分，并提前提醒；五、六年的自然消耗减轻。
- 行动前说明骰子与加减点；成就看过后不再重复弹出。合并重复正文，保留原文和旧选择。
- 发布只包含运行资源；原图保留在本机忽略目录。修复调用限额与页面缓存，新增代码行宽检查和旧档回归测试。

平衡数据及目标对照见 [0.45 平衡验收](docs/施工/0.45-平衡验收.md)，各组验收与截图路径见 [施工进度](docs/施工/施工进度.md)。

## 运行

需要 Node.js 22.9 或以上，无需安装依赖。

```bash
npm start
```

浏览器打开 http://127.0.0.1:5173/ 。端口被占用时用 `PORT=5315 npm start`。

固定剧情可以离线完整游玩。需要 AI 对白时，在“设置”填写 API 地址、模型和密钥，再点击“测试并启用”。网页直连需要服务商允许浏览器跨域请求。

勾选“记住在这台设备上”后，密钥会以明文保存在本浏览器；不勾选则只在本次页面会话有效。密钥不进入游戏存档、存档导出或发布文件。取消记住并再次保存，会移除此前保存的连接配置，不改游戏进度。可随时关闭 AI，继续使用固定文字。

本地代理支持 `.env` 配置，格式见 [配置示例](.env.example)。线上与本机的存档分别保存在各自的浏览器里。

## 发布

`npm test` 运行代码行宽检查和全部回归测试。`npm run build` 构建静态游戏到 `_site/`，仅包含网页、样式、游戏代码、共用 API 配置和实际使用的图片字体，不含本机配置或存档证据。

推送 `master` 后由 GitHub Actions 自动构建并发布 Pages，也可手动运行 `Deploy game to GitHub Pages`。Pages 提供固定剧情与网页 API 直连，不运行本地 AI 代理。

原始大图保留在本机 `art-source/` 并由 Git 忽略，不参与发布。
