# 重生长雍帝王赋

清宫重生题材的文字经营叙事游戏。玩家是重生回到雍正元年的雍正，在三十年里处理朝政，也重新面对七段旧日关系：苏培盛、年羹尧、温实初、允礼、宜修、年世兰、安陵容，另有甄嬛、沈眉庄两条扩展线。

当前版本 **0.32.0**（新版第一、二卷）。旧版仍可通过网址加 `?legacy=1` 进入。

- 在线游玩：https://lynch715.github.io/changyong-emperor/
- GitHub 仓库：https://github.com/Lynch715/changyong-emperor

GitHub Pages 默认进入周制版本；固定剧情可完整游玩。Pages 不运行本地 AI 代理，也不包含本机密钥；可在游戏的“设置”页填写自己的 API（是否可连接取决于服务商的跨域支持），或继续本地运行。线上与本机的浏览器存档分开保存，搬移进度请使用游戏内导出、导入。

## 发布

推送 `master` 后由 GitHub Actions 自动构建并发布 Pages，也可以手动运行 `Deploy game to GitHub Pages`。
`npm run build` 仅将网页、样式、`src/` 和 `assets/` 输出到 `_site/`，不发布本机配置、存档证据或开发服务器。

## 运行

需要 Node.js 22.9 或以上，无需安装依赖。

```bash
npm start
```

浏览器打开 http://127.0.0.1:5173/ 。旧版：http://127.0.0.1:5173/?legacy=1 。端口被占用时用 `PORT=5315 npm start`。

## AI 对白

默认可以不联网，全程使用固定文本。在封面的“设置 · API 与存档”，或游戏底部的“设置”，可直接维护 API 地址、协议、模型、密钥和每日上限。点击“测试连接”发送一次不含游戏记录的简短请求，再“保存并启用 API”。手机无需修改项目文件。

勾选“记住此设备上的配置与密钥”后，刷新、关闭再打开仍会恢复；未勾选则仅本次页面会话有效。记住的密钥保存在当前浏览器本地，不进入游戏存档、存档导出、Git 仓库或 Pages 发布文件。共用设备请勿勾选。可随时“改用固定剧情”保留连接，或“清除本机 API 配置”删除配置与密钥，均不改游戏进度。

本地开发仍支持 `.env` 或 `123.env` 配置（见 `.env.example`）；存在本机代理配置时可以选择代理。使用网页直接连接时，服务商需要允许浏览器跨域请求。

## 0.30.0 改动（2026年10月29日）：新版第一卷

旧版玩法循环混乱、反馈零散，这一版重写了一个精简引擎，先做元年至二年（24 个月，约一小时）。

**循环**：一个月一回合。
1. 月初处置本月要事（主线、关系、两难、政务，按月历排好）。
2. 白天三个时辰，每个时辰选一件：召见、赏赐、下旨、微服、休养。
3. 入夜选一处去，或独寝。情分到「相知」的人会“有话想说”，当夜进入第二幕剧情。
4. 月末结算：本月所有变化、要务进度、下月预告。

**反馈**：每个动作之后都弹出变化标签（国库、民心、朝局、后宫、圣躬，以及谁的情分涨落）；顶栏显示本月累计；首页一句话告诉你现在该做什么。两难里没站在谁那边，那人会有“心结”，情分不再上涨，召见时可以说开。

**AI**：用来给自由度，不是做约束。
- 召见时可以随便说话，角色按自己的性格回应，并由 AI 判断这句话让情分涨落多少（引擎限幅：单句 −5～+4，一次召见最多 +8），值得记住的话会写进人物的记忆，之后的对话会用到。
- 下旨可以写任何事，AI 推演后果并给出对五项局势和人物情分的影响（引擎限幅：单项 ±8，正向合计 ≤12）。
- 夜里的一段、剧情选择后角色的一句回应，也由 AI 写。
- 没有 AI 时全程可玩：召见挑话题，旨意从拟好的三道里选。

**文字**：主线 12 幕、关系线 18 幕、政务与支线 10 幕重写为白话，去掉旧稿里的规则说明腔。原稿保留在 `src/v2/content.js`，改写稿在 `src/v2/rewrite*.js`。

**文件**：`src/v2/`（`engine.js` 规则，`data.js` 人物与月历，`ai.js` 提示词，`main.js` 界面，`v2.css` 样式），本地服务新增 `/api/v2`。测试 `tests/v2.test.mjs`。

## 文字修订机制

原稿正文写在各卷内容文件里，并且保持不动，旧存档里的原话才能对得上。玩家看到的是 `src/narrative-copy.js` 里的阅读修订稿：按场景编号替换正文和回应。要改某一幕的文字，在这个文件里改，不要改原稿。

## 0.26.0 改动（2026年10月29日）：两难

关系选项原本总有一个“正确答案”：亲近的那一项只加信任、没有代价。这一版在前两年加入四个两难场景，成全一人，便会辜负另一人；想两头都顾，就要付出自己的代价。

| 场景 | 时间 | 两难 |
| --- | --- | --- |
| 七夕两宫 | 元年七月 | 宜修依礼拜月，年世兰扎好了鹊桥灯 |
| 再唱一回 | 二年正月 | 安陵容想当众唱完那支曲，年世兰视为当众打脸 |
| 庆功与笛约 | 二年四月 | 年羹尧的庆功宴与允礼的笛约在同一夜 |
| 城南的疫 | 二年七月 | 温实初想去城南救疫，宫里的调养离不开他 |

- 场景在主线之后出现在御案上，占一格时间，可以不打开，错过即不再出现。
- 成全的一方信任上升；被辜负的一方留下一个“心结”，在补谈之前不能再往亲近处走（合作照常）。补谈占一格，每人有专门的补谈对白。
- 两头兼顾的选项不留心结，但会扣圣躬、国库或心绪。
- 之后与当事人相见时，开场会提起这件事；心结未解，就一直提起。
- 内容在 `src/dilemma-content.js`。原有 181 个场景的正文与效果不变，旧存档照常读取；伪造的心结记录会被存档校验拒绝。

另修正：对女性角色的自由对话框显示“亲口对她说”。
