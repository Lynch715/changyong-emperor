# 重生长雍帝王赋 · 本地运行包

2026年10月27日，运行版本0.13.0，正文快照15。首版元年至二年55逻辑单元。本包是本地交付，未发布到线上。

使用Node.js 22以上，在本目录执行：

```sh
npm start
```

无需安装第三方依赖。默认地址`http://127.0.0.1:5173/`为季度档，`http://127.0.0.1:5173/?world=weekly`为普通周档；迁移副本从“更多 → 设置与存档 → 旧档接续”进入。若需要独立来源验收：

```sh
PORT=5251 npm start
```

再访问`http://127.0.0.1:5251/?world=weekly`。端口改变会切换浏览器存储来源，原进度仍在原地址，须先到原来源导出，再在新来源显式导入。

开始恢复前阅读[交付保护与恢复说明](docs/交付/交付保护与恢复说明_S13-06.md)，保全当前单档、全部八槽和迁移包。项目压缩包不含浏览器实时存档；普通八槽集合须离线提取单档，完整迁移包可恢复独立副本。离线工具只写新文件。

本包包含正式运行文件、资产和恢复工具；完整测试、设计与历史验收在项目源码／施工前回退包中。`npm test`适用于完整项目源码，运行包不带测试目录。正式服务不开放QA fixture、脚本目录、回退包或设计原稿。
