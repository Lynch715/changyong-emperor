# 《重生长雍帝王赋》本地交付 v0.23.0

2026年10月28日。阅读版22（原始历史正文保留），存档格式2。本包用于本机运行，不含密钥、玩家实时进度、开发跳年入口或测试存档。

## 启动

安装 Node.js 22.9 或以上版本。在本目录执行 `npm start`，浏览器打开 http://127.0.0.1:5173/?world=weekly 。无需安装依赖。若5173已被其他项目使用，执行 `PORT=5315 npm start`，打开相应端口。停止服务按 Ctrl+C。默认固定文本，无网络也可完成三十年剧情。

八卷依次开放元年至三十年：初卷覆盖第一、二卷；之后每卷封卷后，在“存档—长卷接续”显式复制到下一卷。实际费用、月账、人物意愿、子女出生和成年日期随真实规则推进。当前季度档另在 `/?world=quarter`；不要将季度入口与周制入口混用。

## DeepSeek Flash

已预设以下配置，联网尚需本机密钥：

```dotenv
AI_API_KEY=
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-flash
AI_PROTOCOL=chat-completions
AI_DAILY_LIMIT=100
PORT=5173
```

复制 `.env.example` 为 `.env`（也支持用户指定的 `123.env`），仅在本机编辑 `AI_API_KEY`，再执行 `npm start`。也可设置环境变量 `DEEPSEEK_API_KEY`。`.env` 与 `123.env` 自动加载；两文件都有同名配置时以后者为准（显式环境变量仍优先），密钥不会进入游戏存档或运行包。设置页面选择“本地服务端代理”，保存后才启用联网。`AI_API_KEY` 优先；其他服务商的专用密钥不会被默认发送给DeepSeek。

按2026年10月28日[官方接入说明](https://api-docs.deepseek.com/quick_start/)，当前模型标识为 `deepseek-flash`，旧 `deepseek-v4-flash` 是兼容别名。使用官方[JSON输出](https://api-docs.deepseek.com/guides/json_mode/)方式，关闭思考模式，发送有限且按知情范围筛选的上下文；程序继续校验事实、角色、候选命令与当前意愿。接口失败、超时、空内容、截断和无密钥时保留固定文本，不循环重试、不改变规则结果。

高级选项仍可配置其他服务商、Responses或Chat Completions。普通服务商使用严格JSON Schema；DeepSeek使用JSON对象及完整结构提示。浏览器“自带密钥”只保留本页内存，刷新即清除，可能受跨域限制；推荐本地代理。

2026年10月28日已完成真实Flash样本验收：最终九人语气、长记忆、秘密隔离、接话与解析13项全部通过。此前3次模型回复被原校验拒绝且固定文本保持，保留真实失败证据；这不是未来回复100%可靠的保证。详见包内S15-04记录。

## 存档与回退

自动档、上次进度、恢复前备份与五手动槽保存在当前浏览器来源。相同域名但端口不同是不同来源；换端口不会自动带来原进度。常规备份用“存档—导出当前存档／全部档案”。长卷跨机器或端口使用“导出紧凑完整接续包”，再从“选择封卷周档或完整接续包”导入；单个长卷档与完整包用途不同，完整包保留副本来源和八槽。

原项目 `output/` 中已有S13、S14各阶段回退包仍保留。本轮按用户新要求不再生成巨型施工前回退包，也不逐次比对玩家八槽。需回退时先导出当前进度，在空目录解包原阶段包，用 `python3 scripts/verify-source-package.py 包路径 --extract-to 新空目录` 校验；不要覆盖工作目录或清浏览器存储。运行包可用同一命令验证。
