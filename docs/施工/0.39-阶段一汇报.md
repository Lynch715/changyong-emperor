# 0.39 阶段一：入卷确认与含蓄亲密氛围

## 实现范围

原执行提示中的露骨性描写、胁迫后的同意及绕过边界的要求未实现。本轮改为成年非亲属、明确自愿的含蓄相处，保留各档的意愿边界。设置项名为“亲密氛围”，不是成人描写模式；仓库、运行时 AI 提示均不请求露骨内容。

- 新增 `audience.js`：年龄确认和阅读偏好仅存设备，不进入游戏存档。未确认先显示入卷页；离开停在原页。确认后默认开启含蓄氛围，设备可记住关闭状态。
- 夜话与两情相悦者的私下召见可加入含蓄氛围；书信、下旨、剧情回声不加入。亲属、心结、低情分、凶与大凶不启用；一档也不绕过意愿与亲属边界。太后和亲王不会被写成亲密对象。
- 夜话遇到空结果、模型拒答或坏 JSON，安静回退到固定文字，不额外扣资源。
- 资料中的 `minor` 改为 `secondary`，单独声明成年属性。0.38 的 `minorDone` 和动态故事旧分类仅在读档迁移处识别，运行时使用 `secondaryDone`、`secondary`，不丢既有进度。
- 修改文件：`src/v2/audience.js`、`ai.js`、`data.js`、`engine.js`、`fate.js`、`main.js`、`outings.js`、`roster.js`、`v2.css`；新增 `tests/v2-v039.test.mjs`，更新旧字段迁移测试。
