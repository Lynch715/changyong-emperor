# 0.42 大型政务事件：史料边界与设计

## 史料锚点

- 雍正四年（1726）京师米价腾贵，朝廷将京仓好米五万石分给五城平粜。此为本次“米价风潮”中开仓平粜、同时核查供应的历史锚点。见[中国人民大学清史研究所《医疗与卫生》](https://iqh.ruc.edu.cn/old/qdshsyj/ylyws/e15b04f6f3d1468eb91071ff60d1c252.htm)。
- 雍正六年（1728）夏四月，松江府志记有“大疫”，乡人称“虾蟆瘟”；现有材料无法据此确认现代病原或具体病名。见[闵宗殿《明清东南地区疫情研究》](https://agri-history.ihns.ac.cn/scholars/minzongdian/minzongdian1.htm)。游戏使用“痢症”等当时可理解的病名作情境演绎，不把它与“虾蟆瘟”混为一谈。
- 明清方志研究显示，水旱、饥荒与疫病常相互叠加；痢疾见于多地记录。清代安徽研究指出疫病多见于夏秋，沿江河湖、交通与贸易要地较易受波及。参见[《明清东南地区疫情研究》](https://agri-history.ihns.ac.cn/scholars/minzongdian/minzongdian1.htm)及[《清代安徽疫病及社会应对》](https://xb.yctu.edu.cn/_upload/article/files/6f/4d/d20dce5a41acbf5d9480be80f575/deb01731-979c-491b-9e4b-6e906f074fa2.pdf)。
- 清代荒政记载包含水、旱、蝗、风、雹、雪、霜、地震等灾种；灾后赈济、转运、核册与地方官考核是事件链的制度背景。具体场景为合乎时代背景的虚构演绎，不声称是某年某地的原始奏折。

## 事件范围

新增八类大型事件：河决淹田、连旱接蝗、痢症流行、地震毁城、京城大火、漕运大阻、赈灾大弊案、米价风潮。每类三种开场变体，共二十四个版本；各事件固定省份与症结，后续不因随机数而推翻已做选择。

## 玩家处置链

事件通常跨四个月，三种更复杂的变体跨五个月：急报与勘察、主要处置、中途回报与补救、善后、最终回奏。处置选项会记入存档；专项拨款经国库账目结算；民生、吏治、财赋通过对应省份的现有结算路径反馈。已任命地方官的能力与忠诚会影响最终结果。逾期迟延会增加损失。

每局不重复抽取已经出现过的变体；全部二十四种用完后才重新抽取。事件链未结束时不再另开一宗大型事件。旧存档仅惰性补上新增字段，不改存档版本、结局门槛或原有历史档案。
