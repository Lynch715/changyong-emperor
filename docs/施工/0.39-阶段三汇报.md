# 0.39 阶段三：自己安排一日与一夜

## 做了什么

休养先进入“今天想怎么歇？”页面。接入 AI 后，可以从五个建议开始写，最多二百字，也可以请在场、已经见过面的成年人作陪。“照常歇着”仍是原来的休养，不加花费。关闭 AI 后只留固定路径。

夜里先选人，再写今晚的安排，最多三百字。每个人有五条建议，点入后还能改。不写时仍走旧的剧情或夜话；写了才先掷一次骰，一档不掷。夜话放宽到二百至六百字，休养二百至四百字。两种 API 协议都为长回复多留了篇幅，服务端会限制上限。

数值由引擎决定。夜里圣躬最多减二、加三，情分沿用原有上限与骰面限制；凶与大凶不增加圣躬，人物婉拒亲近。自拟休养圣躬加四至十，大凶加四、凶加六、大吉加十；花费只走内帑，零至三万两。作陪的人通常加两点情分，凶加一点，大凶不加，但会记得这一日。内帑不足或请不到人时不花时辰。

没收到可用的 AI 回话时，继续用固定文字。休养回退只做普通休养，不收自拟花费，也不增加作陪情分；夜里即使回退，也保留已掷的骰面，大凶不会改成情分上涨。

## 与原提示的差别

没有实施露骨性描写、强迫或药物情节被写成同意、亲属亲密，以及一档绕过边界。替代为成年非亲属之间、自愿而含蓄的“亲密氛围”，可随时关闭；所有自由度都尊重人物意愿。对明确越界的自拟安排先拦下，不送模型、不花时辰。固定剧情正文和选项未因本阶段改写。
