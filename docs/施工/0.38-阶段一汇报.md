# 0.38 阶段一：国库与内帑

- 引擎、数据、AI 和界面接入两本银账；新增 `economy.js` 集中处理银子精度、显示、月账和旧档迁移。旧剧情的国库效果 1 点折 10 万两。礼物有独立的内帑价格；宫宴、关系剧情里的宫内花费和微服路费走内帑。赈灾、河工、军费仍走国库。
- 初始国库 800 万两、内帑 50 万两；三卷月进账分别 55、65、80 万两，内帑每月 4 万两。旧存档国库按 800/60 换算一次，缺少内帑、月账时补默认值。
- 拨银放在下旨页，与下旨一样占一个时辰，不增加首页行动种类。国库拨进内帑扣朝局 2，反向拨银加民心 2。月末分别列出两本账的进出和余额。
- 新增 6 项回归测试，涵盖旧档走完一月、银子显示、效果换算、礼物与不足拦截、双向拨银、AI 内帑限幅、家宴与 72 月回放。既有测试改为按万两检查财务值，保留非财务的 0—100 限制。
- 固定策略（每月批折、休养、送茶、独寝，剧情按脚本优先项选择）实测：12/24/36/48/60/72 月国库为 1410/1870/2490/3210/4080/4910 万两；内帑为 97.4/144.8/192.2/239.6/287/333.8 万两。脚本 `scripts/v2-economy-replay.mjs`。这是一个固定策略样本，不代表所有玩法的平衡结论。
- `npm test`：780/780；`npm run build`：通过。375px 首页、下旨、拨银结果、赏赐页通过，无横向溢出，按钮至少 44px。截图在 `output/playwright/v038/stage1-*.png`。
