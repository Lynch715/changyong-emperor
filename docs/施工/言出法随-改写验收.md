# 言出法随直接改写初验

日期：2026-11-09。当前项目：`Lynch715/changyong-emperor`。本文保留初验范围；发布前补充审计见 [0.46 发布验收](0.46-审计缓存美术验收.md)。

## 执行范围

- 一档自由输入通过 `fiat.js` 的声明式协议落地，不调用普通旨意的收益限幅、资格、定员和时辰检查。
- 支持国库、内帑、四项局势指数、剩余时辰、人物情分/忠诚/能力/住处/去留/心结、现有及自定职位、地方三值、新政、标记与要务状态。
- 史实之外的新制度、科技、新人物等保存到世界事实，并进入后续模型上下文。它们属于叙事设定，不自动新增经营面板或独立模拟系统。
- 数值永久设定按最终绝对值保存，跨月及读档恢复；后续同字段指令替换旧设定，`unlock` 解除。切换二、三档后暂停锁定，已经生效的世界与数值保留。
- 输入保留成年、自愿和亲属边界。非亲密的强制行政命令和皇嗣学习安排在一档不再被词语误拦。

## 回归

`npm test` 包含原有208项与新增7项测试。新测试覆盖：

1. 一亿两精确入账为10,000万两，零时辰与未办要事不拦自由指令，不额外掷骰。
2. 中文数词、小数单位、复合指令不会只执行可识别的一半。
3. 四位妃嫔可同时任大学士，突破资格、定员与单次三人限制；自定头衔、人物住处和出场实际生效。
4. 永久圣躬、银两、情分经过12个月、保存及读取仍保持；可暂停、修改和解除。
5. 无效字段、非有限值、溢出、原型路径整体失败，源存档不受部分修改。
6. 世界事实更新、撤销、存档往返，旧存档与其他档位兼容。
7. 下旨、召见、夜间、休养共用协议；事实进入后续上下文；缺少执行内容的模型响应被拒绝。

## 应用内浏览器

使用新版应用内浏览器，独立地址 `http://127.0.0.1:5487/`。未访问在线玩家存档。

- 未连接模型：从新局切换一档，在初始要事未办时输入「国库增加一亿两，内帑增加100万两，圣躬永久设为100」。结果是国库10,800万两、内帑150万两、圣躬100；三个时辰保留，刷新继续后数值仍在。
- 复杂指令：使用本地固定模型响应测试完整传递与提交流程，无外部模型调用。输入破格任命及修建蒸汽铁路后，人物页实际显示「大学士」，任命历史标明「言出法随」，首页可展开已保存的铁路设定。
- 默认桌面尺寸与390×844手机尺寸检查通过，手机页面宽度390，未横向溢出；输入框独占一行，按钮与文字可正常显示。浏览器控制台无警告或错误。
- 截图保存在忽略目录 `output/fiat-qa/desktop.jpg`、`output/fiat-qa/mobile.jpg`。测试模型服务已停止。
