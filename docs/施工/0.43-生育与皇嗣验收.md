## 已实现的规则

- 受孕对象仅为 C06—C10，以及 SECONDARIES 中原分类为「妃嫔」的人。男性角色、南风馆角色和后来被任命的其他身份不因此获得受孕资格。
- 普通入夜与「有话想说」的剧情留宿都接入一次判定。关系须满足 canBeTender，本人 wish 必须为 open，已有孕期、休养期、暂缓、不生育及拒绝的夜晚均不重复触发。
- 基础受孕概率 15%；请温实初调养花 1 时辰，本月及随后两个月增加 8 个百分点。现有圣躬低于 60 时减 5 个百分点，低于 40 时减 10 个百分点。全部随机使用原 rand(s)，不用 Math.random。
- 华妃未停欢宜香时概率为零。人物页可停香；M03 三个实际撤香分支、L07 会写入 stop_huanyi。旧档已有 M03 或停香解释记录时补回标记。L07 改为停香、调养和不作保证，保留原本的情感选项。华妃报喜有专属对白。
- 一至两个月后以本月要事复诊报喜。晋位、厚赏、低调各自明示内帑花费和情分；晋位遵守现有位分定员，不能再晋时明确改赏。皇后明面上依礼照应，各宫暗中较量。
- 真孕约十个游戏月，每月一次安胎，可花 1 时辰或内帑 1 万两，照护 +1。照护反馈显示累计值。
- 每胎预排一至两次暗算，类型为香料、饮食、落水；提供可以核验的具体线索。识破加情分、后宫并减风险；加派照护有明确费用；忽视加风险，可能失胎。照护会降低失胎概率。失胎后另出安抚事件，提供三个月休养期，不重置关系阶段，不制造永久心结。
- Y10 未有真孕时建立 fake 记录，温实初可以立即辨破或按一个／两个月后复查。fake 不得安胎、受孕或诞育。已有真孕时改写为被人换脉案的诬告，保留真实孕期；剧情留宿触发 Y10 也走同一套状态。
- 到期事件依次选皇子／公主／天意、输入名字或选三个候选、点缩略图预览并确认婴儿图。出生后全屏庆贺，起居注写实际出生年月、生母、皇子或公主及姓名。
- 满十岁按真实出生年月出一次少年换图事件。皇嗣分区展示立绘、生母、年龄、生辰和近况；只能更换当前年龄段及对应性别的图。十岁起可读书、考校；家庭同过节庆会有孩子的正文与近况，皇帝独自过节不虚构孩子在场。
- 原游戏到六年末封卷，新增自愿入口「继续宫中岁月」，七年正月起沿原月历和资源结算继续家庭生活，支持孩子真正满十岁。没有孩子、不生育的玩家也可接续，不设生育门槛。

## 新存档字段与迁移

继续使用原 SAVE_KEY，不另覆盖其他槽位；load 支持版本 1、2，读取时只在内存补字段，不自动写回原 JSON。旧数值、人物旧字段、日志、排期、任命、未知扩展字段均保留。

| 字段 | 用途 |
| --- | --- |
| version: 2 | 原结构版本 1 加一 |
| pregnancy[id] | start、due 为「年-月」；care、risk、known、fake 按要求保存 |
| pregnancy 的附属字段 | announce 为报喜的月序号；threats 为暗算发生的孕月，handled 防重复；caredAt 限制当月照护次数；fake 的 resolveAt 为复核月序号 |
| children[] | id、mother、name、sex、born、art.infant、art.youth、traits、notes；出生时 youth 留空，十岁时选择 |
| children[].youthChosen | 已完成十岁换图，防止重复弹出 |
| people[id].wish | open / later / no，旧档默认 open；商量不以资源强换同意；改为暂缓或不生不扣情分 |
| family | tonic 调养有效期、discussed 当月商量记录、recovery 失胎休养期限 |
| flags.stop_huanyi | 实际停用欢宜香 |
| pendingBirth | 正在取名／选婴儿图的步骤；刷新可继续，完成前不能推进月份 |
| familyArt | 正在更换的皇嗣、年龄段、是否必须完成；十岁必选步骤同样阻止推进月份 |
| familyContinuation | 已从第三卷结局选择继续宫中岁月 |

当前孕期不会因为后来商量「暂缓」或「不生」而被删除；这两个意愿阻止新的受孕。人物原有完整关系路线和不生育结局不以孩子为条件。

## 未成年人保护

1. K 编号及 children 名册加入与 KIN 同类的永久排除，不能进入原成人角色入口；年龄增长也不解除。
2. planAllowed 检查孩子目标、编号、名字及皇嗣／皇子／公主等称呼，禁止亲密、恋爱或性安排。普通读书可用。
3. 所有带游戏状态的 AI 上下文都有皇嗣实际年龄与「未成年」标注；调用层统一加保护要求。原对话、夜话、赏赐回声、剧情回声对孩子直接退出，不调用模型。
4. 自拟对话、旨意、休养和夜晚在发送前拦截越界安排；AI 返回涉及皇嗣的越界文案也会丢弃，退回固定文字。使用模拟恶意输出验证，不需要真实模型服务。
5. 生育、安胎、失胎、诞育、成长全部使用固定家庭文案。家庭事件不请求成人 AI 回声，成人开关不改变生育判定和这些文案。
