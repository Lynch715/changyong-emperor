# 0.41.1 政务平衡修复：本地验收结果

本报告记录0.41.1发布前的本地验收。用户已明确授权提交并推送到Lynch715/changyong-emperor的master，发布结果以对应Actions运行及线上version.json为准。

## 结论

已修复核实免费替代执行、财政缺少常态支出、朝局自动收益叠加、无点名督抚持续崩坏及灾折排队等问题。旧档保留，结局门槛未提高。固定与随机各200局72个月，另有四组各200局对照，共1200局。

原随机仍是不会主动任命或启动新政的压力策略，未用更温和的新策略替换。固定主策略使用新规则区分查核与执行：急灾优先批准，普通工程按该省民生是否低于70决定拨银，其余查核；核实优先、一律拨银与节用分别单列。0.41.0旧固定原本普遍选核实，因此前后固定主策略同时包含规则和适应决策的变化，不能解释成单参数因果效果。

## 规则修改

1. 核实收二万两。工程、赈务、边务、文教、民情核查不直接获得执行收益，原折保留，不能重复核实；后续仍须批经费。刑名、吏治、钱粮核查以账证整顿为主。灾情不会被留中、交部议或核实取消。
2. 各卷每月税收仍为52、62、75万两，军政常态支出新增20、26、32万两；先收本月税，再支付军政及补欠。缺口记入publicArrears，下月优先补足，不能用清空国库逃费。户部任职银两收益缩至四分之一。
3. 京职形成与地方吏治有关的朝局支撑目标，每月最多回归一点，当前朝局高时不再持续叠加；查实密折的直接奖励在朝局达到70后停止。
4. 未点名督抚仍由常任衙门署理，地方三值按季向50缓慢回归；能臣每两月推动一次。撤去第二卷额外的全国民心月扣一，避免地方已扣后重复惩罚；全国民心与实际地方民生偏离超过八点时逐月收敛。
5. 新政完成后每项每月一万两维持费，无银则暂停；收益按季向75改善，不再每月将所有省无限推至100。
6. 新灾折置前，新办结回报自动收存至已收回报和月末小结，不再生成需要再批的一道折。首页局势有免费查阅回报入口，即使没有时辰也能收存旧待阅回报。
