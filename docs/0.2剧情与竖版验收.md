## API调整

1. 本地识别出一项偏好，不再因此跳过混合句剩余内容的AI解析。明确识别的偏好与拒绝会合并保留；本地已明确的拨款金额不被模型擅改或重复投递。
2. 原句属于咨询，或模型将其标为query，均清除行动候选。假设咨询直接问答，无须先进行一次动作解析。
3. 未连接AI时，对混合句里未解出的行动要求进行澄清，保留已识别偏好，避免沉默漏办。
4. 为完成选择后的角色接话增加reaction请求。程序先提交确定结果、立即展示手写对白，再允许模型接话。模型不结算数值、不追加承诺或关系阶段。
5. 接话文本只附加保存一次，旧事务、跨进度或已经离开的场景不会接受旧回复；重读不再次请求。失败和超时保留手写正文。
6. 模型上下文包含明确写好的角色可见场景，不直接发送主线内玩家独有的内心独白。

结构化输出格式按[官方OpenAI文档](https://developers.openai.com/api/docs/guides/structured-outputs)核对，仍由程序检查行动和叙述的语义边界。真实服务商调用尚未验证。
