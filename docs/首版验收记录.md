# V1.2 首个可玩原型验收记录

验收日期：2026年10月23日。程序版本：0.1.0。运行地址：`http://127.0.0.1:5173`。

这是第一阶段开发记录，不是完整 V1.2 制作目标的最终验收。原 V1.0、V1.1、V1.2 Word 文件未修改。

## 本次实现

- 元年至二年8回合；12个主线、七线各前两节点、6个政务、4个群像支线、8个日常模板，以及F00阶段收束。
- 七线为苏培盛、年羹尧、温实初、允礼、宜修、年世兰、安陵容。允礼采用果郡王身份，四条男性线保留。
- 确定性规则负责数值、排程和结果；自由输入先拟定方案再确认；复合命令整体校验。
- 按人物保存偏好、原始对话、拒绝边界、知情范围和到期承诺；预约预占容量，履约不重复扣费。
- 自动档、上一回合档、5个手动档、导入导出、恢复前备份和多标签写入冲突处理。
- 可选AI代理和会话内自带密钥模式；默认固定文本与规则输入可独立游玩。
- 雍正、宜修两张透明立绘与御案背景三个样张接入。

## 应用内浏览器实际试玩

通过 Codex In-app Browser 在 localhost 操作页面，实际走完12主线、14相知、6政务及4群像节点，到达F00。主路径涉及以下操作：

1. M02向苏培盛输入“朕夜里不爱浓茶”，产生来源明确、仅两人知情的偏好。
2. 按回合推进七线节点与财政清理链，保留政务核验和回访时点。
3. G04输入“先拨一半，派张廷玉核账，暂不公开怀疑，并加押运”，预览显示补给6点、押运2点、承办人为张廷玉。确认后继续G05、下一回合的G06。
4. F00先取消一次封卷预览，确认仍能继续，再正式封卷。结算显示12主线与14相知均已处理，七人均在场。
5. 刷新后自动档恢复到封卷状态。回到旧事簿，仍可见元年告诉苏培盛的饮茶偏好，知情范围未扩大。
6. 将通关进度存入第五手动档，再通过“备份并载入”新开局。当前试玩入口停在第一回合，未提交M01选择；第五档保留本轮验收进度。
7. 检查控制台，没有捕获到页面错误。

## 尚未完成的制作与验证

- 三年至三十年、七线后四节点、暮年番外、生育与成人婚姻的实际剧情尚未开放。
