# S09-03 候选权限与叙述来源矩阵

执行版本：v0.9.3，2026年10月25日。对应原计划 S09-03；不修改原 Word。七核心线、允礼身份、原剧情、费用与奖励仍由原引擎决定。

## 动作与来源

| 输入或回包 | 程序处理 | 验收依据 |
| --- | --- | --- |
| 今天就照你说的办 | 不向模型开放整幕三个选项；意思未明确则澄清 | 旧版实际产生留茶候选，新版零候选；IAB复现 |
| 今天就按第一项办 | 只开放当前可见事件、当前人物的第一选项 | IAB实际推进M02，手写回应与原心绪+2只落一次 |
| 第十二项／与另一人讨论第一项 | 不截取数字尾字，不借当前场景擅自选择 | 专项自动测试 |
| 明晚同你去御园走一趟等支持的改述 | 有限同义词归入原散步动作；无时间或无法识别仍澄清 | 改述、缺项与日期用例；不承诺任意问法 |
| 不要安排散步／不要拨6点 | 否定主要动作时不生成正向候选 | 自动测试，原句来源逐项核对 |
| 先拨一半、承办、知情与押运 | 金额、人员、知情及押运从本地原句确定；仍按6+2核账 | 原引擎预览、扣费与库存日程专项 |
| 模型返回event、promise、week-plan或自拟参数 | 拒绝；解析回包仅允许candidateId与sourceText | 两种协议结构、额外字段及参数篡改用例 |
| 旧目录／伪造目录／中间结果换动作 | 按当前存档及原输入重建目录，重新核对每个引用 | 目录伪造、库存已预占、resolve二次核对 |
| 本人不爱浓茶、只谈公事 | 本地明确偏好和边界可以保存；模型不得互换类别或补造意愿 | IAB保留饮茶偏好，未终止恋爱；否定与转述专项 |
| NPC喜好／假设提问／不要终止恋爱 | 不作为玩家当前偏好或拒绝写入 | 本地解析与模型记忆来源专项 |

解析接口仅允许 `{type:'candidate', candidateId:'A1', sourceText:'原子句'}`。ID是本次输入、当前人物、当前场景与当前状态生成的临时引用，不是长期授权。目录最多16项、一次最多3动作；来源一致且整组预览通过后，仍走原确认、CAS和事务提交。模型澄清只允许固定代码，程序映射为提问，不直接展示模型编造的系统提示。

## 局部对白

| 叙述内容 | 处理 |
| --- | --- |
| 普通近况闲聊 | 通过人物、结构、知情和关系边界校验后可显示，IAB有正向例 |
| 新任免、孩子、成婚、婚约、亲密旧事、复合、正式约定、政绩或奖励已完成 | 检出高影响声明时，必须有当前人物可见、实际引用的世界记录，并与其中原句对应；无来源回退 |
| 引用一个真实但无关factId | 不构成凭据，不能把留灯事实当成修井或成婚证据 |
| 玩家单方面声称／动作已提交 | 披露转述与动作日志不能单独证明孩子出生、工程完成等结果 |
| 尚未修好、未成婚等明确否定或未决 | 可以如实表达；反问、双重否定及零宽字符不作为绕过理由 |
| 回包夹带actions、stats、他人speakerId | 拒绝；不写世界、不改关系与奖励 |
| reaction校验失败 | 原手写结果及已提交事务保留，失败计数一次，不自动重试 |

采用有限自然语言检测与保守回退，不是所有中文表达的事实证明。现有知情、前世秘密、停香与关系边界检查继续生效。真实模型的人格稳定性和长对话评测尚未验收；三层记忆按S09-04、上下文按05、接话生命周期按06、组合专项按07继续。

## 玩家可感知的结果

明确选项仍得到原人物专属回应与原有回报；普通合规聊天可以使用AI回复。含糊安排会被追问，模型不替玩家表态，不把一句体谅写成关系升级或项目完工。命令子句不再次送入闲聊请求，减少重复调用与矛盾接话。
