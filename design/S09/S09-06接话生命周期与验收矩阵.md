# S09-06 接话生命周期与验收矩阵

日期：2026年10月25日。版本0.9.6，正文版本9。范围为新提交的手写剧情之后可选AI接话；S09-07组合输入与真实服务商仍另行验收。

## 提交与接话顺序

1. 原规则预览和提交先完成，正文快照、钱款、时间、人物意愿与回报按原引擎保存。
2. 手写专属回应立即展示。只有本次确实产生的新剧情提交、当前为原场景且已启用AI时，才登记一次接话尝试。
3. 接话使用提交后的只读副本。成功只附加AI文本，失败只结束本次尝试；两种情况均不重做规则事务。
4. 离开、重读、换档、恢复或版本改变后的结果丢弃。完成、失败、取消或中断的尝试不由重读自动续发。

## 绑定与写入

| 绑定 | 核对位置 | 作用 |
| --- | --- | --- |
| 存储来源和写入标识 | 请求领取及实际写锁内 | 区分周制、季度、迁移副本及同游戏同revision的另一份恢复 |
| gameId、worldVersion、revision | 领取、响应后、写锁内 | 禁止把旧结果写进新进度 |
| 场景ID和场景键 | 同上 | 区分重复日常和实际场景快照 |
| 本次进入序号及重读标识 | 同上 | 离开再返回同幕、同幕改为旧事重读也属新阅读场次 |
| 事务、人物和正文版本 | 同上 | 接话只属于本次实际提交的那句话 |
| 应用和模型配置版本 | 同上 | 旧请求不跨版本或配置接续 |
| 请求唯一ID和尝试状态 | 导入校验及保存 | 一次尝试不可覆盖旧AI文本或在失败后隐式重试 |

回包通过响应前检查后，等待写锁期间仍可能换档，所以在锁内再次核对。通用写入保存前也核对原state对象和写入标识，跨窗口最终由既有CAS继续保护。

## 等待、取消及失败

| 情形 | 结果 |
| --- | --- |
| 正常等待 | 手写回应可读；仅本次活跃场景显示等待提示 |
| 离开、另入场景、开始新输入或页面关闭 | 取消活跃接话，旧请求结束时不清掉新等待状态 |
| 传输忽略AbortSignal | 仍由请求域竞速退出，不让旧Promise阻塞新输入 |
| 14秒期限 | 覆盖响应头与正文解码；超时只记一次失败 |
| 主动取消 | 已实际发出的调用保留调用计数，不误记服务失败 |
| 服务失败或非法文本 | 保留手写回应、数值、账目、时间、意愿及旧正文，尝试状态failed |
| 读取已中断存档 | requested仅表示当时已发起尝试，不表示正在后台等待；不显示永久等待、不自动补发 |
| 成功及失败后重读 | 沿已保存快照展示，零新请求、零新结算 |

新尝试状态放在本次新正文的可选`reactionRequest`字段；旧正文无此字段时不补写。字段只含来源、版本、请求ID、请求时revision和有限状态，不存模型密钥、地址、任意回包字段或服务商错误原文。旧AI文本保持原样。季度复制迁移保留这份历史来源，不把旧请求当作新世界待执行任务。

## 验收集合

32项新增生命周期专项覆盖正常附加、离开返回、重读、换档、同revision恢复、换来源、换人物事务正文版本、换配置、领取及成功／失败写锁竞态、跨标签页CAS、取消旧请求后的新请求、读档及迁移、恶意字段、两协议传输取消、响应体超时、错误正文取消及定时器清理。原554项保留，最终586项通过。

IAB独立5204来源实走周制M01等待时离开、推进到M02成功接话、两幕重读，以及季度M01服务失败后重读。模拟服务3次请求：旧幕延迟返回、下一幕成功、季度服务失败；失败重读未增加第4次请求。14秒超时与严格并发竞态使用自动测试的受控Promise／虚拟时钟，未冒称浏览器实等14秒或真实服务商。

实际浏览器为桌面1280×720。实体手机、软键盘、完整两年浏览器通关与真实API仍待后续。
