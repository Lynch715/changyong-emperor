# S09-05 上下文检索与请求预算矩阵

日期：2026年10月25日。版本0.9.5。范围为当前人物可见上下文、相关旧事检索、检索修订即时生效与长谈请求预算；接话生命周期按S09-06继续。

## 保留与筛选顺序

| 层次 | 处理 | 验收重点 |
| --- | --- | --- |
| 当前约束 | 当前双方意愿、边界、未决事项、已接受及待改期约定保留；约定仅发必要身份、状态、日期和用途字段 | 未赴约不写守诺；停止回响不改变规则中的当前意愿与待办 |
| 当前场景 | 当前人物参加的场景、合法选项、实际结果及可见来源优先 | 已有来源不因落在最近30条以外丢失；无关人物不见该幕 |
| 合法动作目录 | 解析请求完整保留程序目录及原句 | 不截断、不替换候选、金额、人物、日期或原子句 |
| 相关旧事 | 从当前人物全部合法可检索事实、经历、偏好和摘记中按本次话题检索 | 最近12组以外的相关分歧能被找到；前世、听说、处置及世界证据仍分开 |
| 近期对白 | 保留实际原句，按原顺序加入预算；整条加入或整条省略 | 不在一千字处切断末尾否定，不把半句改成相反含义 |
| 摘记表达 | 只发有原句来源的atoms，保留时间、知情及状态；省去重复text与私人核对批注 | 摘记只证明说过，不能证明同意、完成或守诺 |

相关性采用程序词片段匹配、否定及未决标记和时间排序；这是有限检索，不承诺任意中文语义都能准确召回。完整历史原文保存在旧事簿，不随请求预算删减。

## 长度与回退

- 基础上下文按包含当前输入的JSON长度控制在40,000字符以内。
- 实际客户端请求按44,000字符以内控制，低于本地代理48,000字符上限。代理模式测发往代理的完整JSON；自带密钥模式把协议提示、Schema及JSON转义计入实际请求体，两个协议分别量算。
- 当前约束、场景结果、来源或完整动作目录本身过大时，在联网前给出固定文本回退，不移除必需约束凑长度，不增加调用数，不重试，不回滚已提交动作。
- 长度按JavaScript字符串字符数计，与现有代理检查一致；不把字符预算等同服务商token预算。真实服务商模型窗口仍需实测。

## 修订与知情

| 情况 | 预期结果 | 证据 |
| --- | --- | --- |
| 更正偏好 | 当前偏好可用，旧偏好及确定引用旧原句的NPC回响退出 | 新旧偏好链与短原句引用专项 |
| 停止摘记原句 | 原句退出摘要、近期对白与相关检索 | IAB5202停止来源前后两次请求 |
| 新AI回复改述旧话 | 新回复保存所用上下文的有限来源引用；来源停止或更正后，改述及后续依赖回复退出检索 | 改述来源链专项与最终浏览器导出 |
| 旧无来源回复 | 保留原文，对确定的原句引用作保守过滤 | 不能声称可识别所有历史中文改述 |
| 恢复来源 | 可再次从原句检索，保留完整修订链 | S09-04恢复证据与S09-05回归 |
| 待补谈及关系阶段来源停止 | 历史引文可退出，当前关系边界与未完义务仍约束 | 当前mandatory与规则状态分开核对 |
| 停香、扩展表态来源停止 | 不通过派生观察或原私下回复重新发送 | 停香及甄嬛来源停止专项 |
| 玩家草稿、私有偏好及他人私聊 | 不发给NPC；核对批注不进入请求 | 草稿、visibleTo与跨人物专项 |

新对白来源字段只含kind与id，限制种类、长度及数量；不存密钥、完整上下文或私人核对批注。旧消息不补写来源。只读和检索不改变存档，新增来源只随本次实际新增的AI回复保存。

## 本轮验收集合

25项新增上下文专项覆盖100条原审计复现、密集长谈、相关旧事实与旧分歧、当前来源优先、私聊与草稿隔离、更正停止恢复、长句否定、重复摘要、超大核心回退、接话来源、两协议与两模式实际请求、代理处理函数、合法候选、派生观察、扩展表态、改述来源链及恶意导入。原529项保留，共554项通过。

IAB使用独立5202来源，从209条消息起点核对旧事召回、仅合作、未赴约、停止原句及派生AI回复、无新增费用或日程变化。仅桌面1280×720；真实服务商、实体手机和软键盘未验收。
