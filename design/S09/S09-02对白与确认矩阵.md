# S09-02 对白与确认矩阵

版本0.9.2；2026-10-25。沿完整施工计划S09-02，不改变原剧情结果、费用、七条核心线、人物ID或存档结构。

## 如何分流

| 玩家行为 | 本轮交互 | 原规则约束 |
| --- | --- | --- |
| M01、M02等已审定普通主线问答 | 单击直接展开原专属回应 | 必须实际不花时间、不跨日、不变更正式约定或发展意愿；原效果与事务保留 |
| 七核心同场合作、明确距离 | 单击直接展开 | 仅原场景成本为零的合法选项；信任与纪念按原选择结算一次 |
| 七线暖选项、正式阶段推进或协商恢复 | 先确认 | 发展意愿和阶段不能因省弹窗而自动改变；暖选项说明会表达愿意更进一步 |
| 已付过时间的短追问 | 选接话方式后直接显示原文 | 必须仍是同一真实相处来源，不添时间或奖励，原一次追问限制保留 |
| 普通闲聊、感谢、饮茶偏好、明确拒绝 | 直接回复 | 原句来源、偏好和边界即时记录；闲聊不刷数值，NPC意愿不被玩家拒绝改写 |
| “能不能明晚散步”等咨询 | 直接答建议，没有待执行命令 | 可只读试算日期与日程，不预约、不占格、不交物，不把建议写成已答应 |
| 问题＋明确正式行动 | 问题先答，行动列候选确认 | 聊天请求只含问答子句，命令不交给聊天模型宣布完成 |
| 新占格、约期改期取消、宴请、购礼赠礼、伴侣活动 | 先核对 | 包括零费用安排和同场零额外格送礼；核对预算、物品、人物和时间 |
| 政务处置、任免处罚等 | 先核对 | G04零拨款也须确认；未开放的能力仍拒绝或澄清 |
| 自拟G04军需方案 | 完整参数预览，再确认落笔 | 军费、押运、承办、知情范围、核验及总费用都显示；6＋2仍只扣8点 |
| 重生披露、核对副单分享、时间向前 | 先核对 | 秘密确认前不写人物消息；取消仍留输入草稿；跨日期显示实际目标时日 |

“普通对白”用已审定动作清单和实际试算结果共同判定。单看总费用为零不够：逐项费用不能相互抵消绕过，实际日期、时段、承诺、库存、关系阶段、双方发展意愿和秘密来源都要复核。未知动作默认保留确认；任意无效动作仍由原引擎拒绝。

主线当前直接回应清单：M01全部、M02全部、M07 skill、M08 listen、M09全部、M11 clear／polite／unsure。七线普通合作／距离按成本与当前实际状态复核；R03-02边书为通信，仍确认。R07有已阅未分享副单时保留知情核对。其余正式主线处置继续确认；不是把全部零费用按钮一起跳过。

## 问答与固定文本

已识别咨询、普通闲聊、“说说这个安排”“来聊聊”直接进入回答，不先要求AI解析动作。明确但未识别的命令仍走解析或具体澄清，例如“去御园走一趟”不会被吞作普通客套。

固定回答补入七人的疲倦、心愿、致谢；可依据实际存档回答剩余周格、已正式确认的约期，并只读试算散步等安排。G04半额咨询说明六点军费与两点押运，仍保留核账与回执的未决性；无权读军册的人不获该笔具体数字。

已知规则问题可由程序直接答，其他问题可选一次AI问答；失败使用固定回复。此次只验证模拟调用与失败回退，没有真实服务商测试。短问答和原有16条上下文不等于长期摘要；三层记忆仍按S09-04。

## 取消、重复与保存

明确偏好／拒绝先按原消息留源；取消正式行动不撤回。普通选择、正式确认共用原commit、原子事务、幂等和存档CAS；提交期间阻止重复点击。只是新交互入口，不添加另一套奖励逻辑。

过去的正文、纪念、周报、AI回复按原样重读，加载旧档不补写本轮对白；新回答才写入新的消息记录。原五份Word、S01、三张样张与CSS保持。本轮只完成S09-02，不将S09-03至07或S10全面体验一并勾通过。
