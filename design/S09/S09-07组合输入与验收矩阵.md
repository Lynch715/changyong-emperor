# S09-07 组合输入与验收矩阵

收尾日期：2026年10月26日。实现 v0.9.7；正文快照版本仍为9。对应原计划S09-07，本项只调整输入候选的生成与澄清，不调整钱款、时间、人物意愿、库存或存档引擎。

| 输入组合 | 应有行为 | 验证 |
| --- | --- | --- |
| 偏好＋军需咨询＋拨一半＋核账＋押运＋保密 | 各句保留；本地金额6、承办允祥、押运2，合计支出8；模型不能改参数 | 自动；沿用候选权限与代理测试 |
| 如果／假如开头，后接赠礼、宴席、秘密 | 假设统摄整句，仅咨询，无行动候选、偏好或秘密披露事实 | 自动 |
| 明晚与你散步？／送礼？／取消？／改期？ | 保留问号，不预约、不取消、不改期；后续另一条明确命令仍单独解析 | 自动＋IAB散步问句 |
| 不要取消／不要把原约改到… | 否定为对白，无变更候选；不能把别人的唯一原约当成“与你” | 自动＋IAB否定取消 |
| 明晚送礼并陪你散步 | 保留第二项；缺独立日期、时段时追问，不能默吞或擅自继承时间 | 自动 |
| 偏好＋只谈公事＋两个明确活动 | 同一正式核对；取消核对只取消候选，偏好与边界仍已说出 | 自动＋IAB取消和确认 |
| 真实礼物＋小宴 | 预约预占；履约才送出持有新物和记小宴支出。无物、重名物、同物二送不得预支 | 自动履约；IAB预约预占 |
| 备制＋尚未产出的赠礼 | 不把将来制作当成当前实物；整组先澄清 | 自动 |
| 多原约取消／改期＋新约 | 按原人物、日期、时段定位；编辑分别读取原时段与目标时段，保留取消及改期历史 | 自动 |
| 改日再谈＋次日晚间预约 | 原节点留未完成，不代替同意；新约单独预留，整组正式核对 | 自动＋IAB允礼首谈 |
| 重生秘密＋其他命令／听者不同／多人／未知人／否定披露 | 整句留草稿，不投递对话、不调用模型、不生成可执行候选 | 自动；IAB错听者混合句、草稿与最终导出 |
| 单独向当前同一人披露 | 仍走原秘密正式确认，仅生成该听者的披露事实 | 自动 |
| 多宾客宴席＋咨询／偏好 | 二至三位已相见且可到场者；按输入姓名顺序落座，主题与双格、费用照引擎 | 自动；IAB宜修、苏培盛清茶小席 |
| 未知第四人／外任／未相见／时段冲突／四项行动 | 追问或整体预览拒绝，不丢名单、不截断、不扣资源 | 自动 |
| 旧计划确认前库存、格数已变化 | 原revision计划不能提交，重新核对 | 自动 |
| 听说某项活动／依你说的办 | 清楚转述不预约；含糊执行意图仍澄清，不能借“转述”吞掉命令 | 自动专项及原权限回归 |
| 季度混合咨询＋明日陪你看灯 | 沿用旧promise与正式确认，不迁移成周计划，不改旧正文 | 自动 |

程序候选仍逐条携带原句来源，模型只能回选候选ID，不可指定金额、人物、日期、礼物等参数。最多三个子行动；澄清未完成时，界面不进入行动执行。已有的偏好与明确拒绝独立记录，秘密分支在消息记录之前整体拦截。

本项40项专项及全量626项通过。IAB使用独立 `http://127.0.0.1:5206`、固定文本、两个合规测试副本；真实服务商、实体手机、软键盘和完整两年浏览器通关未验证。解析为有限句式；未明确或未支持的表达应追问，不承诺任意自然语言均能识别。
