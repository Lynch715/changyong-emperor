# S10-04 周计划与时间顺序验收矩阵

2026年10月26日，v0.10.4；正文快照仍为9。以原周引擎、预占、费用和实际时钟为准，完成周计划的状态与顺序呈现。

| 要求 | 实现与证据 |
| --- | --- |
| 可用、预占、已用 | 摘要保持实际格数；另列全部未来约定预留预算，明确履约时才支出。草稿与候选标记未预占；自动及IAB通过 |
| 日期时段排序 | 当前周和周外约定均按日期、日间／晚间排序，源数组不改；自动乱序添加、IAB先添5日再添3日仍按3／4／5日显示 |
| 未来赴约 | 未来预约没有直接执行按钮，使用“沿日程向前”进入原时间推进核对，遇到更早事件先停；IAB从5日预约入口先停3日 |
| 到期执行 | 仅到期且原引擎允许的活动显示“照约去做”；入场、意愿、容量和待办仍由原规则核对；点击再检查当前状态 |
| 完成与重读 | 已完成显示已核销，仅可重读原回应；自动及IAB两项完成和刷新恢复通过 |
| 改期 | 新约注明原日期时段，独立历史区显示原约及改往日期；原记录、事务和正文保持 |
| 取消与失约 | 未执行取消释放预占及预算；历史区保留取消记录。过期旧约仅据实记失约，不能倒放、取消或改期；失约消耗不写成已完成活动 |
| 旧约与封卷 | 迁移旧约待协商从修改安排进入原流程，不能当普通候选直接接受；封卷不提供写入按钮；自动验证 |
| 存档保护 | 原5173两世界16槽key／raw一致；独立5214终态与原引擎重放在新随机ID对齐后完整一致，历史正文未变 |
