# S10-01 御案阅读入口与验收矩阵

2026年10月26日，v0.10.1。沿用原竖版、深木与哑金外框、墨绿操作区和米白正文。只做御案阅读入口，不将S10-02至06一并标为完成。

| 场景 | 展示与操作 | 验证 |
| --- | --- | --- |
| 新开局返回御案 | 当前必读故事先呈现；场景按钮仍走原权限与日期检查，无虚构回应 | 自动＋IAB |
| 已完成一幕 | 显示存档中的原回应，带真实人物与日期，可重读全文；不重新生成摘要或AI接话 | 自动＋IAB |
| 同日多个片刻 | 按日期、真实完成事务顺序选最近的剧情或已完成日常，不能依赖对象插入顺序 | 自动 |
| 未履行的未来约定 | 不冒充已经发生的回应；预占、已用和实际收支分记 | 自动＋IAB读书预约 |
| 本周变化 | 只读当周实际流水、当前可用、预占、已用；未来预算明确尚未支出 | 自动＋IAB |
| 下一项期待 | 从原时间停留点取得日期和标题，当前到期用“眼前等你”，未来用“接下来” | 自动投影＋IAB |
| 完整周表 | 默认收起，摘要仍显示余量、预占和已用；展开后的原安排、履约、改期和取消入口保留 | IAB |
| 重读、返回与预约重绘 | 同一游戏、来源和周内保留开合；换游戏、来源或周重置，状态只在页面内存中 | IAB同周保持；重置逻辑核对 |
| 不展开周表也可安排 | 御案周变化区有直接活动入口，进入原表单与正式费用核对，不直接提交 | IAB |
| 原手写及AI历史正文 | 展示转义原文、CSS限制预览行数，全文入口保留；不改存档正文、版本或存储键 | 自动＋原档比对 |

本项新增8项只读投影测试，全量634项通过。新版Codex In-app Browser使用独立5208、固定文本，实际DOM视口319×664，scrollWidth为319。属于窄屏浏览器验收，未冒称实体手机、软键盘、其他尺寸或全量键盘验收。其他尺寸与全面交互按S10-06继续。
