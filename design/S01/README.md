## 玩家一周会怎样玩

开局先看见还活着的故人，第一次回应有人接住。留茶之后，玩家可把一格投给交班缺口，也可留给读书或散步；一周末看到交接单真的有人签，或者留下了一页字与一段愿意再谈的话。项目的后续回报到日期才来，人物也会带着自己的近况找来。

全内容样例47项经历包含回访与F00，另8个日常模板是可选库。八个重点周六格共48格，样例剧情占19格，留29格自由安排；八个可选延展周最多再给48格。这证明内容可以排入，不是要求玩家每周照一张推荐表打卡，更不表示数值已平衡。

九人各有可接的话题、自己的喜欢和不喜欢，也有恋爱后不谈公事的相处。七核心线单独验收，扩展二线另计。拒绝、仅合作、保留分歧和暂缓都能被接住；相守后的日常有主动靠近、玩笑和不愿散场，不把爱情全部写成照护与办公。
